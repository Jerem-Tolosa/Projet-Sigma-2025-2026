### Projet ICU Sigma 2025-2026

Le projet ICU Sigma est un projet collaboratif d'étudiant pour répondre à une demande.
Ici l'objectif du projet de visualiser les différents ICU (îlots de chaleurs urbains) sur le territoire départemental du Tarn.

Les différents objectifs ont été les suivants : 

- Mise en place d'une base de donnée géographique
- Création de scripts statistiques
- Réalisation d'un application web de visualisation de ces différents ICU ainsi que les différentes statistiques qui y sont liés
